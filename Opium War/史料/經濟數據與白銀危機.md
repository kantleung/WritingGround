## 關鍵數據（1840年前後）

### 英國方面（格雷厄姆1840年演說數據）

| 項目 | 金額 |
|------|------|
| 英國每年從對華貿易獲得的財政收入 | **420萬英鎊** |
| 其中：茶葉關稅 | 366萬英鎊 |
| 英屬印度每年從對華貿易獲得的收入 | **200萬英鎊**（印度年總收入約2000萬鎊） |
| 中國→印度年白銀流入 | 平均 **130萬英鎊**，1840年達 **170萬英鎊** |

這組數據揭示了英國決策者的真實焦慮：
- 對華貿易的財政重要性極高
- 印度殖民財政高度依賴對華貿易
- 白銀從中國流向印度是英國全球財政體系的關鍵環節

### 清朝方面（學術估算）

| 項目 | 數據 |
|------|------|
| 鴉片戰爭前每年白銀淨流出 | 約 1000萬兩（估算範圍 600-1500萬兩） |
| 1821-1840年白銀外流總量 | 約 2-3億兩 |
| 銀錢比價變化 | 1820年1兩≈1000文 → 1840年1兩≈1600文 |
| 清朝年財政收入 | 約 4000萬兩 |

白銀外流→銀貴錢賤→農民以銅錢換白銀納稅→實際稅負增加約60%→社會矛盾激化。這是清朝禁煙的經濟邏輯。

## 三角貿易結構

```
         ┌──────────────────────────┐
         │       英屬印度           │
         │  (孟加拉鴉片產區)        │
         └──────────┬───────────────┘
                    │ 鴉片 →
                    │         ┌──────────────────────┐
                    │         │      清朝中國         │
                    │         │  ┌────────────────┐  │
                    └────────→│  │ 鴉片消費者     │  │
                              │  └───────┬────────┘  │
                              │          │ 茶葉/絲綢  │
                              │          ↓            │
                              │  ┌────────────────┐  │
                              │  │ 廣州出口商     │──→ 英國
                              │  └────────────────┘  │
                              └──────────────────────┘
```

### 利潤鏈

1. 東印度公司在孟加拉壟斷鴉片種植和加工
2. 鴉片在加爾各答拍賣給私商（「港腳商人」）
3. 私商走私至廣州外海的伶仃島
4. 中國走私商接貨，經由遍佈沿海的走私網絡分銷至全國
5. 茶葉和絲綢從廣州合法出口至倫敦
6. 白銀從中國沿海流向印度，部分經印度轉回倫敦

廣州體制下的合法貿易（茶葉）和非法貿易（鴉片）實為一體——前者為後者提供了匯兌和物流的掩護。

## 一個常被忽略的諷刺

在1834年之前，英國東印度公司壟斷對華貿易。1834年公司對華貿易壟斷權被議會廢除後，「自由貿易」的私商迅速填補真空。但這些所謂的「自由貿易者」並不自由地銷售英國棉布（中國人不買），而是自由地走私鴉片（中國人要買）。

自由貿易理論的美麗之處在於：它假設各方都能從交換中獲益。鴉片貿易的血腥現實是：一方獲益，另一方（清朝國家、中國社會底層）遭受毀滅性打擊。成癮性商品的「自由貿易」不是互利交換，而是掠奪。

## 修正主義者迴避的核心問題

Gelber等修正主義者反覆強調英國要求的是「自由貿易」。他們沒有回答的是：

> 如果英國真正關心的是自由貿易，為什麼在1839年之前半個世紀，它從未認真嘗試通過合法外交途徑要求中國開放市場，而是一直通過走私毒品來平衡貿易逆差？

答案可能是：英國決策者並不天真。他們知道中國沒有理由主動開放市場（中國的經濟自給自足），也知道除了鴉片，英國沒有任何中國需要的大宗商品。鴉片不是自由貿易的例外——它是自由貿易在結構性不對稱面前的唯一「解決方案」。從這個意義上說，**鴉片貿易並非自由貿易的偏差，而是自由貿易的真相。**
